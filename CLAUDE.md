# JSGame — бриф для Claude

Обучающая браузерная игра: игрок учит JavaScript, когда пишет **настоящий** код, а код меняет живую сцену.
Стадия: концепция. Кода игры пока нет.

## Кто пользователь и как с ним говорить
- Говорит по-русски, в JS новичок. Отвечать по-русски, объяснять простыми словами, без жаргона без пояснения.
- Главный риск — бросит, если станет сложно или скучно. Объяснения короткие, с аналогиями, победа должна быть видна сразу.
- Хочет учиться приёмам сильных программистов: короткие записи, цепочки вызовов, профессиональные переносы строк, инструменты (DevTools, хоткеи, Prettier и т. д.).

## Стиль кода (во всех примерах, уроках и в коде самой игры)
- Строки — в обратных кавычках: `` `#frame-picker` ``.
- Отступ 2 пробела.
- Переносы строк решает Prettier, руками не выравниваем (решение 2 ниже). Длинные цепочки Prettier сам раскладывает «лесенкой»: каждое звено с новой строки, точка в начале, сдвиг на 2 пробела. Короткие цепочки он собирает в одну строку, и так и оставляем.
- Ширина строки: 60 колонок для кода игрока (терминал, примеры, подсказки), 80 для исходников самой игры.

```js
const frame = document.querySelector(`.frame`);

document
  .querySelector(`#frame-picker`)
  .addEventListener(`input`, ({ target }) => {
    frame.style.backgroundColor = target.value;
  });
```

## Визуал
Референс: `docs/reference/mood.webp`. Пиксель-арт с дизерингом: заброшенное техническое помещение, свисающие кабели, ЭЛТ-мониторы, огромный проём в стене на спокойное море и небо с облаками, одинокая девочка спиной к нам. Настроение тихое, одинокое, «после конца».

Палитра почти двухцветная:

| Роль | Цвет |
|---|---|
| Серые (от тёмного к светлому) | `#1B1B1B` `#222325` `#2C3034` `#343638` `#3D4248` |
| Сигнальный синий | `#579AF3` |
| Светлый синий | `#81B5F6` |
| Синий отсвет на сером | `#49607E` |
| Блики, облака | белый |

Правило: серое значит обесточенное, синее — живое, по нему идёт сигнал.

## Механика «Штиль» (полностью: `docs/MECHANICS.md`)
Механика согласована как основа. Источник истины — `docs/MECHANICS.md`, ниже только главные законы.
- **Мир — это настоящий DOM.** Комната — обычные HTML и CSS в iframe-песочнице на отдельном origin. Код игрока работает с ней по-настоящему: `querySelector`, события, `style`, `classList`. Рендер рисует DOM пиксель-артом 320×180 и сводит любой цвет к палитре по яркости, с растром Байера 4×4.
- **Синее значит «прямо сейчас связано с настоящим».** До финала синим светится только то, что сделал код игрока. Красного нет нигде.
- **Пока игрок печатает, код не выполняется.** Реагируют только две вещи: закрытый литеральный селектор (провод к первой найденной вещи) и призрачный датчик на `addEventListener`.
- **Запуск** — `Ctrl+Enter` или рубильник. Каждый раз чистая страница, затем пошаговая трасса выполнения. Медленно показывается только первый запуск задачи.
- **Проверяет девочка.** Она пользователь кода и создаёт настоящие события. Задача решена, когда она перестаёт пробовать. «Почти» не засчитывается.
- **Ошибки** показываются дословным текстом браузера, разбором по частям и одной фразой по-русски. Наказаний нет.
- **Пять сущностей:** провод, датчик, импульс, автомат, свет. **Четыре инструмента:** терминал, рубильник, телетайп, щуп. Новые механизмы под каждую тему не добавлять.
- **Прогресс** — одни сутки на станции, 8 мест вдоль морской стены. Решённые файлы продолжают работать на мониторах. Очков нет.
- **Код профи** оправдывается только настоящим измеримым последствием. Где разницы в работе нет, игра прямо так и говорит.

## Решения пользователя (31.10.2026)
Ответы на вопросы из `docs/MECHANICS.md` §11. Не пересматривать без его слова.
1. **Проём закрыт ставнями до финала.** Слышно море, видна белая щель. Небо и море открываются только в последней сцене: первый синий, который сделал не игрок.
2. **Форматирование — как у Prettier.** Лесенку руками не навязываем: на длинных цепочках она получается сама, короткие цепочки живут в одну строку. `Shift+Alt+F` в терминале — эталон.
3. **Ошибки — дословно по-английски с первой главы.** Под текстом браузера разбор по частям и одна фраза по-русски. Русского перевода вместо оригинала нет.
4. **Играет и со звуком, и без.** Звук и видимый двойник равноправны: всё, что несёт звук (шум, реле, автомат, телетайп), обязано читаться глазами. Игра полностью проходима без звука.

## Ассеты
Рецепт, конвейер скриптов и рабочий промпт — `docs/ASSETS.md`. Готовые спрайты — `assets/sprites/`, палитра для игры и скриптов — `assets/palette.json`.
- Генерация через Codex (MCP `codex-imagegen` у пользователя на Windows-ПК, модель `gpt-6.1-terra`): спрайты вещей, девочка, кадр ЭЛТ-терминала, фоны комнат. Генерировать можно смело, по 4 варианта.
- Терминал игрока — `assets/sprites/terminal.png` (серый, выключенный), экран для кода — в `terminal.json`. Отсвет экрана и сам код рисует игра.
- Строго в палитре референса (9 цветов выше). Сцена 320×180, целочисленная пиксельная сетка, без сглаживания.
- Сгенерированное приводить к палитре и проверять скриптом. Ни одного цвета вне палитры.
- У каждой вещи 2–3 состояния, и это кадры спрайта: CSS-класс = кадр. У девочки 8 действий: идти, стоять, ждать, трогать, крутить, нажимать, нести, сесть.
- Провода, импульсы, свет на полу и растр рисуются кодом, а не ассетами.
- Код в терминале набирается JetBrains Mono (лигатуры выключены), а не пиксельным шрифтом.
